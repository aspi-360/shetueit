# ShetueIT — Modern Services Section & Business Solutions Website

A modern, responsive, and high-performance corporate website designed for **ShetueIT**, a premier software and business IT solutions company in Bangladesh.

## 🚀 Key Features

* **11 Core Business Services**:
  1. Accounting Software (`calculator`)
  2. Inventory Management Software (`package`)
  3. POS Software (`shopping-cart`)
  4. ERP Solutions (`workflow`)
  5. HR & Payroll Software (`users`)
  6. MLM Software (`network`)
  7. Dealer Management Software (`truck`)
  8. Custom Software Development (`code-2`)
  9. Website Development (`globe`)
  10. E-commerce Website Development (`store`)
  11. Membership Website Development (`id-card`)
* **Premium SaaS Design**: Deep navy typography (`#0f172a`), royal electric-blue accents (`#2563eb`), clean white surfaces, and subtle soft-shadows.
* **Pure Vanilla Codebase**: Built strictly with standard HTML5, CSS3, and vanilla ES6+ JavaScript. Zero heavy frameworks or build tools required.
* **Fully Responsive**:
  * Desktop (3 columns)
  * Tablet (2 columns)
  * Mobile (1 column)
* **Interactive Features**:
  * Category filter tabs ("All Solutions", "Business Software", "Web & E-Commerce")
  * Interactive "Learn More" modal dialog with key capabilities
  * Auto pre-fills the contact consultation form when inquiring about a service
  * Lucide vector icons with embedded fallback SVG support

## 💻 How to Run Locally

### Method 1: VS Code Live Server (Recommended)
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension (by *Ritwick Dey*).
3. Right-click `index.html` → **Open with Live Server** (or press `Alt + L, Alt + O`).

### Method 2: Direct Browser Launch
Simply double-click `index.html` to open it in any web browser (Chrome, Edge, Firefox, Safari).

---

## 🌐 Deploy Free on GitHub Pages

1. Push this repository to your GitHub account.
2. Go to **Settings** → **Pages** (under the "Code and automation" section).
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**.
5. Your website will be live at `https://<your-username>.github.io/<repo-name>/`!
